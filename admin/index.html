Giriş

Yönetim sayfası değişiklikleri doğrudan GitHub deposuna kaydeder. Giriş için GitHub erişim anahtarınızı yapıştırın.

Anahtarı nasıl oluştururum?
  1. GitHub’da Settings → Developer settings → Personal access tokens → Fine-grained tokens sayfasını açın.
  2. Generate new token’a tıklayın, bir ad ve süre verin.
  3. Repository access: “Only select repositories” → kapsayici-almanca-2026.
  4. Permissions → Contents: “Read and write”.
  5. Oluşan anahtarı kopyalayıp buraya yapıştırın.

Oturumlar

Bir oturumu açın, eğitim videosunun YouTube bağlantısını ve çalışma notlarını ekleyin. Bitirince alttaki Yayınla düğmesine basın.

Kaydedilmemiş değişiklik yok.
